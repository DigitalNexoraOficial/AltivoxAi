# AltivoxAi V2

Landing premium (Next.js 15+) + panel admin HTML estático en `/public`.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm start
```

## APIs

- `POST /api/lead` — captura leads (guía, contacto, calculadora)
- `POST /api/chat` — chatbot
- `POST /api/n8n` — bridge n8n
- `GET /api/ig-image` — assets IG

## Panel

- `/login.html`, `/dashboard.html`, `/clientes.html`, …
